# Changelog

## Plus 1.6.0 — 2026-10-30
- Free, Plus and the mobile room are now free, with direct download links and no activation.
- Removed the payment backend, credentials, checkout and recovery-code components.
- Added optional Buy Me a Coffee support to website and Plus Settings.
- Mobile uses the Windows room artwork, foods, toys, furniture and pet family.
- Added mobile pet sizing, time/weather controls, Catch the Bug and Treat Drop.
- Kept local saves, backup import/export, offline play and earned-coin progression.
- Updated the guide, privacy, terms, downloads and release checksums.

## 1.2.0 — 2026-10-16
- Fixed companion taps changing identities/positions; taps now greet, with selection in Family and pet-count regression tests.
- Added autonomous companion snacks, naps, play, dances and greetings.
- Added permanent Seaside Cottage, Woodland Cabin and Moon Suite bundles with matching wallpaper, floor, bed and desktop house.
- Added movable desktop furniture, compact/hide controls and a walk-through home entrance. Escape no longer opens the room.
- Added dino, tiger and parrot, three coats each, dance/wave animations and distinct synthesized voices.
- Added up to four named household pets, separate needs, shared progression, purchasable slots and solo mode.
- Added friendly chats, dances and pillow duels, plus owner-aware click reactions.
- Added a five-meal pantry with a free fallback meal.
- Added Memory Garden and Firefly Rhythm to Windows and mobile.
- Rebalanced earned coins, persisted care reward cooldowns, three arcade lives, 30-minute regeneration, 20-coin refills and free practice.
- Preserved old saves, coin balances and species unlocks; added migration and household regressions.
- Updated the showcase, mobile Family page, guide, offline cache and Windows installer.

## 1.1.0 — 2026-10-14
- Added owner and pet names, personalized greetings and progress-preserving rename.
- Packaged a per-user Windows installer; added save-folder single-instance protection.
- Added the showcase website and mobile PWA, backups, daily goals and treat hunt.
- Fixed name previews and preserved custom names while changing preview species.
- Added search/social metadata, structured data, installation FAQ, sitemap and verification file.
- Added proprietary licensing, repository docs, CI, and portable build/test paths.
