# Contributions and support

This is a proprietary project. The public repository is provided for inspection and issue reporting, not as a general reuse license. Read LICENSE before using any source or assets. Ask the owner before submitting substantial code or artwork; contribution rights must be agreed separately. Opening an issue does not transfer ownership of your work.

For a bug, include the app version, OS, steps, expected/actual behavior, and a screenshot if useful. Never include credentials, private account details, or full player-save files. Check existing issues first. For authorized code changes, run the documented checks and describe validation and limitations in the PR.
